# ptcgBattle — 火红叶绿风格 UI Mockup v2

## 设计原则
- **4:3 画面比例**，完全还原 GBA 屏幕感
- **全像素风格**，字体、边框、图标均为像素渲染
- **无手牌横滑区**，手牌通过"卡牌"菜单进入背包界面查看
- 四个主按钮：战斗、卡牌、宝可梦、结束

## 5. 视觉规范

| 元素 | 规格 |
|------|------|
| 画面比例 | 4:3 固定（如 480×320 逻辑分辨率，整数倍缩放） |
| 字体 | 像素等宽字体，8px/16px 两档 |
| HP条 | 48px宽 × 4px高，黑色1px描边，绿(>50%)→黄(20~50%)→红(<20%) |
| 信息框 | 白底 + 2px黑色边框 + 2px圆角，内边距4px |
| 对话框 | 底部占画面约25%高度，同样白底黑框 |
| 按钮光标 | ▶ 三角形，选中时闪烁 |
| 能量图标 | 8×8px 像素小圆，按类型着色（⚡黄 🔥红 💧蓝 🌿绿 ...） |
| 背景 | 像素绘制的战斗场地（草地纹理+天空渐变） |
| 精灵 | 卡牌图像素化处理，或使用原版宝可梦像素精灵 |
| 动画 | 攻击→精灵前冲/闪烁，受伤→HP条平滑下降+精灵闪红 |
| 翻页 | 左右滑动或 ◀▶ 按钮，带页码指示 |

## 6. 交互流程总结

```
主界面
 ├─ 战斗 → 招式选择 → 执行攻击 → 回到主界面(对手回合)
 ├─ 卡牌 → 背包界面(8页翻阅) → 使用/返回
 ├─ 宝可梦 → 队伍界面(2页) → 交换/返回
 └─ 结束 → 结束回合 → 对手回合
```
