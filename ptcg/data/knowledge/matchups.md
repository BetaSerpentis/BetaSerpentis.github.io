# PTCG 对局分析

> 适用环境：简中标准赛制 G/H/I 标（SV4-SV9）
> 注意：F 标（SV1-SV3）已退环境，以下分析基于 G/H/I 标卡池

---

## 一、主流卡组概览

### 沙奈朵ex（超系 / 2阶进化）
- **核心**：拉鲁拉丝 → 奇鲁莉安 → 沙奈朵ex
- **机制**：特性「精神拥抱」从弃牌区填超能到备战宝可梦（放 2 个伤害指示物为代价）
- **打法**：铺伤指物给沙奈朵ex自己，然后用「月光幻影」打出高伤害（20 × 双方场上伤指物数）
- **优势对局**：慢速卡组、依赖宝可梦特性的卡组
- **弱点**：怕 Boss 抓杀关键中间体（奇鲁莉安）、怕撤退干扰
- **关键克制卡**：玛纳霏（防备战区伤指物）、Boss 抓杀奇鲁莉安断链

### 多龙巴鲁托ex（龙系 / 2阶进化）
- **核心**：多龙梅西亚 → 多龙奇 → 多龙巴鲁托ex
- **机制**：招式「幻影突袭」造成伤害同时向对手备战宝可梦放伤指物
- **打法**：铺伤策略，累计伤指物到斩杀线
- **优势对局**：备战区人多的小人牌卡组
- **弱点**：怕玛纳霏（防备战区伤指物）、怕快攻抢血
- **关键克制卡**：玛纳霏、大阳伞

### 喷火龙ex（火系 / 2阶进化）
- **核心**：小火龙 → 火恐龙 → 喷火龙ex
- **机制**：特性「燃烧之魂」伤害随己方已拿奖赏卡增加
- **打法**：前期铺场填能，中后期高伤害碾压
- **优势对局**：慢速卡组（给时间发育）
- **弱点**：怕快攻 rush、怕被 Iono/裁判打乱手牌节奏

### 猛雷鼓ex（雷系 / 基础）
- **核心**：猛雷鼓ex（基础宝可梦，可直接上场）
- **机制**：高爆发伤害，基础直接可用
- **打法**：快攻 rush，第一回合准备第二回合爆发
- **优势对局**：进化链长的慢速卡组
- **弱点**：自身 HP 不算特别高、怕持续消耗战

### 刺龙王ex（水系 / 2阶进化）
- **核心**：墨海马 → 海刺龙 → 刺龙王ex
- **机制**：特性每回合给备战宝可梦填 1 水能
- **打法**：刺龙王ex 在备战区持续填能，用其他打手（如水系打手）输出
- **优势对局**：消耗战（持续资源供给）
- **弱点**：怕 Boss 抓杀刺龙王ex

### 钥圈儿控制（钢系 / 基础）
- **核心**：钥圈儿
- **机制**：特性「金属锁链」对手的基本宝可梦无法使用特性
- **打法**：封锁对手特性引擎，限制对手运作节奏
- **优势对局**：依赖特性的卡组（沙奈朵ex、喷火龙ex 等）
- **弱点**：钥圈儿 HP 低容易被秒、一旦钥圈儿被杀锁特性失效

## 二、关键克星关系

| 你的卡组 | 怕什么 | 怎么针对 |
|----------|--------|----------|
| 沙奈朵ex | 钥圈儿锁特性、Boss 抓奇鲁莉安 | 带换位卡、多放奇鲁莉安 |
| 多龙巴鲁托ex | 玛纳霏、大阳伞 | 带老大的指令抓玛纳霏先杀 |
| 喷火龙ex | 快攻抢血、Iono/裁判 | 前期铺满基础、快速检索进化 |
| 猛雷鼓ex | 高 HP 打手消耗 | 带 Boss 抓后排 |
| 刺龙王ex | Boss 抓刺龙王 | 带换位/气球、多放刺龙王 |
| 钥圈儿控制 | 被秒杀后锁失效 | 带换位、保护钥圈儿 |

## 三、针对特定主流卡组的反制卡

### 反沙奈朵ex
- 玛纳霏（防备战区伤指物）
- Boss 抓杀奇鲁莉安（断进化链 + 断填能引擎）
- 钥圈儿（锁特性）
- Iono/裁判（干扰手牌，减少检索资源）

### 反多龙巴鲁托ex
- 玛纳霏（必备！防备战区伤指物）
- 大阳伞（防单只宝可梦被放伤指物）
- 快速打手抢血（多龙进化慢，前期有窗口期）

### 反喷火龙ex
- 快攻打手（在喷火龙完成进化前抢奖）
- Iono/裁判（利用喷火龙特性依赖手牌的弱点）
- Boss 抓小火龙/火恐龙（断进化链）

### 反猛雷鼓ex
- 高 HP 打手（猛雷鼓爆发高但持续输出有限）
- 消耗战策略（拖到猛雷鼓能量耗尽）

### 反刺龙王ex
- Boss 抓刺龙王ex 到战斗场（刺龙王ex 本身输出低、撤退可能高）
- 快速击杀备战区的打手（让刺龙王的填能白费）

## 四、对局中的思维模型

### 知己知彼
1. 判断对手卡组类型（快攻/中速/慢速/控制）
2. 设定对局计划：你想怎么赢？（快攻抢奖 vs 消耗战 vs 控制锁死）
3. 识别对手的关键卡和核心宝可梦

### 对快攻卡组的策略
- 前期铺满基础宝可梦防被 Boss 一回合拿多奖
- 优先找回复/防御手段
- 不要贪心进化打手，先把场铺稳

### 对慢速卡组的策略
- 主动施压，不给他们发育时间
- 用 Boss 抓关键中间体（如奇鲁莉安、火恐龙）
- 在他们启动前抢到 3-4 奖

### 对控制卡组的策略
- 找 Boss 抓控制核心（钥圈儿等）
- 减少自己特性依赖，用直接检索而不是特性检索
- 控制卡组通常是慢速的，可以尝试抢奖获胜

## 五、换备指南（如果赛制支持备牌）

> 简中标准赛制通常不设备牌，但了解换备思路有助于理解针对关系

### 对抗沙奈朵ex时换入
- 玛纳霏 ×1
- Boss ×1（共 3 张）
- Iono/裁判 ×1

### 对抗多龙巴鲁托ex时换入
- 玛纳霏 ×1
- Boss ×1

### 对抗喷火龙ex时换入
- Iono/裁判 ×1-2
- 快攻打手 ×1

### 通用备用卡（可以在所有对局中考虑）
- 崩塌的竞技场：限制对方备战区
- 大阳伞：防伤指物
- 朋友手册：回收资源
