# PTCG 强力组合（Combo）库

> 适用环境：简中标准赛制 G/H/I 标（SV4-SV9）

---

## 一、填能引擎类组合

### 奇鲁莉安 + 沙奈朵ex + 伤害指示物缩放打手
```
填能引擎：奇鲁莉安（特性「精神拥抱」— 从弃牌区填超能 + 给自己放 3 个伤指物）
核心打手：沙奈朵ex（招式「月光幻影」— 20 × 全场伤指物数）
```
- **combo 流程**：
  1. 奇鲁莉安每回合给备战区沙奈朵ex填 1 超能 + 3 个伤指物
  2. 奇鲁莉安同时给对面的宝可梦放伤指物（招式「幻象突刺」）
  3. 沙奈朵ex 上场后用「月光幻影」打出爆炸伤害
- **配套卡**：拉鲁拉丝×4、奇鲁莉安×3-4、沙奈朵ex×3、超级能量回收（回收超能到弃牌区再用奇鲁莉安拉出来）
- **弱点**：怕钥圈儿锁特性、怕 Boss 抓杀奇鲁莉安

### 刺龙王ex + 水能打手群
```
填能引擎：刺龙王ex（特性「水之帝王」— 每回合给备战宝可梦填 1 水能）
打手群：各种水系打手（美纳斯、水君、盖欧卡等）
```
- **combo 流程**：
  1. 刺龙王ex 在备战区不断填水能
  2. 备战区的打手累积能量到足够后上阵输出
  3. 一个打手被打死，下一个已经在备战区挂满能量
- **配套卡**：墨海马×4、海刺龙×3、刺龙王ex×3、水系打手×2-3种
- **弱点**：怕 Boss 抓刺龙王ex

### 大比鸟ex 检索引擎
```
检索引擎：大比鸟ex（特性「闪亮检索」— 每回合可从牌库找任意 1 张卡加入手牌）
```
- **combo 流程**：大比鸟ex 在备战区每回合免费检索 1 张任意卡
- **适用卡组**：任何需要精准检索的卡组（尤其 combo 型卡组）
- **配套卡**：波波×3、比比鸟×2、大比鸟ex×2
- **弱点**：大比鸟ex 自身 2 奖品、进化链占用卡组空间

## 二、高爆发伤害类组合

### 火恐龙 + 喷火龙ex + 高奖品
```
爆发核心：喷火龙ex（特性「燃烧之魂」— 伤害随己方已拿奖赏卡数增加）
```
- **combo 逻辑**：越接近胜利伤害越高。前期铺场填能，中期开始拿奖启动特性，后期一回合击杀对手主力
- **配套检索**：巢穴球（找小火龙）、神奇糖果（跳火恐龙直接进化）
- **弱点**：前期必须苟住、怕 Iono 打乱手牌

### 猛雷鼓ex + 雷能加速
```
爆发核心：猛雷鼓ex（基础可直上，高爆发伤害）
```
- **combo 流程**：
  1. 第一回合铺猛雷鼓ex + 手贴雷能
  2. 第二回合填满能量直接攻击
- **特点**：简单粗暴，对进化卡组的压制力极强
- **配套卡**：雷电山（竞技场，增加雷能填能效率）

### 伤害指示物缩放体系
```
缩放打手类：伤害随对手宝可梦上的伤指物数量增加
```
- **combo 流程**：
  1. 先使用铺伤手段（如多龙巴鲁托ex的招式）给对手场上的宝可梦放伤指物
  2. 累计到足够数量后，用缩放打手一回合秒杀
- **配套卡**：伤指物缩放打手 × 3-4、铺伤宝可梦 × 2-3

## 三、控制/干扰类组合

### 钥圈儿 + 崩塌的竞技场
```
封锁核心：钥圈儿（特性锁对手基础宝可梦特性）+ 崩塌竞技场（限制备战区上限 4）
```
- **combo 流程**：钥圈儿上场锁特性、崩塌竞技场限制铺场，双锁让对手无法运作
- **配套卡**：气球（让钥圈儿 0 撤，遇险随时换下）

### Iono + Boss 的双杀回合
```
combo：先用 Iono 把对手手牌洗乱 → Boss 抓关键宝可梦 → 击杀
```
- **combo 逻辑**：对手手牌被打乱后，无法检索换位/回复/进化卡来回应 Boss

## 四、资源回收类组合

### 夜游记 + 朋友手册 的循环
```
夜游记：从弃牌区回收 1 宝可梦 + 1 基本能量到手牌
朋友手册：从弃牌区回收 2 张支援者到手牌
```
- **combo 流程**：夜游记拿回被打死的宝可梦+能量，朋友手册拿回重要的支援者（Boss、博士）
- **常见配置**：夜游记 × 1、朋友手册 × 1

### 超级能量回收 + 奇鲁莉安
```
超级能量回收：从弃牌区回收最多 4 张基本能量到手牌
奇鲁莉安特性：从弃牌区填超能到备战宝可梦
```
- **combo 流程**：超级能量回收把能量从弃牌区拿回手牌 → 手贴或留作其他用途
- 配合奇鲁莉安特性形成弃牌区→备战区→弃牌区的能量循环

## 五、特殊机制组合

### 反转能量 + 劣势局翻盘
```
反转能量（特殊能量）：当你的奖品数多于对手时，提供任意颜色 × 3
```
- **combo 场景**：你 3 奖 vs 对手 1 奖时，反转能量 = 直接启动任何需要 3 能的打手
- **配套思路**：先放水拿 2 奖品（给对手 1 奖），触发反转能量满状态，然后翻盘

### 双无色能量 + 无色招式打手
```
双无色能量：提供 2 个无色能量
无色招式：只需无色能量即可释放的招式
```
- **combo 场景**：任何「只需无色能量」的招式都可以被双无色加速
